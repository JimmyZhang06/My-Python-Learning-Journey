# My-Python-Learning-Journey

## 项目简介

这个仓库记录本学期的两项 Python 课堂练习。求最大值程序接收五个整数并找出其中最大的一个。几何计算程序接收圆的半径和矩形的宽、高，输出两个图形的面积及周长。为便于比较，几何尺寸使用同一种长度单位。

## 文件说明

- [`find_max.py`](find_max.py) 练习循环与条件判断。可以输入五个整数，也可以直接运行两组示例。
- [`geometry_calculator.py`](geometry_calculator.py) 练习函数拆分与数学计算。支持自定义半径、宽度和高度，结果保留两位小数。

## 代码说明

- **求最大值**。 `mymax()` 用第一个数初始化当前最大值，再依次比较其余四个数。这样即使输入全是负数，初始值也来自实际数据。本题固定比较四次。如果把同样的扫描方式用于 `n` 个数，需要比较 `n - 1` 次，扫描时间为 O(n)，额外空间为 O(1)。
- **几何计算**。圆的面积和周长分别用 πr² 和 2πr，矩形的面积和周长分别用宽 × 高和 2 ×（宽 + 高）。四个公式各用一个函数，圆周率来自 `math.pi`。计算次数与尺寸大小无关，时间和额外空间均为 O(1)。

## 运行方法

在仓库目录用 Python 3 运行。程序只使用标准库。前两条命令运行默认示例，后两条演示如何传入自己的数据。

```powershell
python find_max.py
python geometry_calculator.py
python find_max.py -8 -2 -5 -2 -9
python geometry_calculator.py --radius 2.5 --width 3 --height 4
```

自定义的五个整数的最大值是 `-2`。上面的圆面积和周长分别为 `19.63` 和 `15.71`，矩形面积和周长分别为 `12.00` 和 `14.00`。输入整数个数有误，或几何尺寸为零、负数时，程序会显示参数提示。

## 学习心得与规划

阅读 [Requests 的 README](https://github.com/psf/requests/blob/main/README.md) 时，我留意到它先用一段代码展示调用方法和返回结果，再给出安装说明。我也在仓库里先说明两个程序的用途，再写运行命令和预期结果。求最大值的练习还加了一组全为负数、最大值重复的数据。读者可以复现结果，也能看出我考虑了哪些输入情况。

这次我把两个程序分别提交。第一次推送后，源码出现在仓库里的桌面子目录下。把文件整理到仓库首页后，README 里的文件链接就能直接打开对应程序。这让我意识到，每次提交前都要确认自己在哪个仓库里，检查准备提交的文件，再写一句能说明改动的提交信息。以后回看时，也能追踪每次改动。

以后每学完一个单元，我会选一个能独立运行的练习，试跑一组正常输入和一组边界输入，再提交代码，同步更新 README。下一个练习我计划用 Pandas 读取一周的模拟学习记录，按科目汇总学习时长。我会写清楚每一列代表什么、缺失值怎么处理，并附上一份预期输出，方便自己复查，也方便同学照着运行。
